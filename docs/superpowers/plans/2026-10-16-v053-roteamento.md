# v0.5.3: plano de implementação do roteamento e das otimizações

> **Para agentes:** SUB-SKILL OBRIGATÓRIA: use superpowers:subagent-driven-development (recomendado) ou superpowers:executing-plans para executar este plano tarefa por tarefa. Os passos usam caixas de seleção (`- [ ]`) para acompanhar o andamento.

**Objetivo:** cada tarefa do Claude roda no modelo, no effort e no formato certos: direto ou com agente. O hadouken barra os desperdícios óbvios, sugere a troca de modelo ou effort da sessão e mede o resultado. Também aponta cinco fontes de consumo errado.

**Arquitetura:**
- **Módulos novos em `src/roteamento/`**, todos puros e testáveis: `config`, `regras`, `registro`, `trecho`, `sessao`, `otimizacoes`, `fila`, `retrabalho` e `semana`.
- **Ganchos em código que já existe:** os hooks `guarda-despacho.js`, `prompt-submit.js` e `session-start.js`, a barra (`formato.js`) e o relatório (`relatorio.js` e `consumo.js`).
- **Arquivos novos no plugin:** os agentes ficam em `agents/` e a skill em `skills/roteamento/`.
- **Nenhum hook novo por chamada de ferramenta.**

**Tecnologia:** Node 20+, ESM, `node:test`, sem dependências.

**Spec:** `docs/superpowers/specs/2026-10-16-v053-roteamento-design.md`, aprovada pelo Sr. Garioli em 2026-10-16. Ela é a autoridade.

## Restrições globais

- Sempre em português nos textos e nos comentários, no estilo do código vizinho: comentário explica o porquê e cita a spec (`spec roteamento §N`).
- **Nenhuma função lança.** Toda função exportada de `src/roteamento/` tem `try/catch` e devolve um valor neutro (`null`, `[]` ou `{}`), como o resto do plugin.
- Arquivos da pasta de dados:
  - são lidos com teto de bytes (`lerJson(arq, max)` de `src/estado.js`) e gravados com `gravarJsonAtomico`;
  - um link ou uma pasta no lugar do arquivo é tratado como ausente.
- **Texto que vem de fora nunca volta em mensagem.** Isso vale para o prompt, a descrição do despacho, os argumentos de comando e os nomes de arquivo nos avisos ao modelo. Só entram rótulos fixos e números validados.
- `UserPromptSubmit` e `PreToolUse` continuam no tempo de hoje. O teste de tempo da Task 10 confere: p95 abaixo de 300 ms com um transcript de 5 MB.
- Os padrões de config são todos `true`. Um valor inválido usa o padrão e gera um aviso de texto fixo.
- **Commits:** com pathspec explícito, uma mensagem curta em português, e terminam com `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. No Windows, use o `commit.sh` do scratchpad, porque a guarda dá falso positivo com "hadouken" e `$` no mesmo comando.
- **Antes de cada commit, apague a pasta `Microsoft/`** que a suíte cria na raiz do repositório.
- **Suíte:** `node --test`. Ela tem que terminar com `ℹ fail 0`.

## Foco da revisão

São as cinco classes de entrada mais prováveis de causar problema que os testes de tarefa podem deixar passar. Cada uma ganhou um teste na tarefa dona.

1. **Despacho para agente de plugin com nome `hadouken:x`:** a regex atual de nome de agente recusa `:` e o perfil sai desconhecido. Sem a Task 4, N2 nunca dispara. É testado na Task 4.
2. **G5 de hoje e N1/A1 sobre o mesmo despacho:** um Explore com effort `max` é barrado pelo G5 hoje. A ordem precisa ser G5 antes, depois N1 e N2, depois os avisos, e um despacho só ganha uma resposta. É testado na Task 6.
3. **Transcript enorme, linha quebrada ou parcial no fim:** o leitor do trecho não pode estourar o tempo nem lançar. É testado na Task 7.
4. **Sessão sem registro no `estado.json`,** com o modelo ou o effort desconhecido: não sugere nada. É testado na Task 8.
5. **Duas sugestões no mesmo prompt** (sessão e O5, por exemplo): só uma sai, e o limite de 30 minutos é dividido entre elas. É testado na Task 10.

// src/roteamento/config.js
import path from 'node:path';
import { lerJson } from '../estado.js';
import { ARQ_CONFIG } from '../guarda/config.js';

// Chave `roteamento` do config.json (spec roteamento §6.3 e §9), no mesmo
// jeito de guardaDaConfig: só propriedade própria, só booleano; o que não
// passa usa o padrão (true) e gera aviso de texto fixo com o nome vindo
// desta tabela. Nunca lança.
const CONFIG_MAX_BYTES = 64 * 1024;
export const PADRAO_ROTEAMENTO = Object.freeze({
  negarN1: true, negarN2: true, avisos: true, sugerirSessao: true,
  otimizacoes: Object.freeze({ leiturasRepetidas: true, saidaGrande: true, mcpOciosos: true, contextoFixo: true, compactar: true }),
});
const ehObjeto = (v) => v !== null && typeof v === 'object' && !Array.isArray(v);
const proprio = (o, k) => (ehObjeto(o) && Object.hasOwn(o, k) ? o[k] : undefined);
const copia = () => ({ ...PADRAO_ROTEAMENTO, otimizacoes: { ...PADRAO_ROTEAMENTO.otimizacoes } });

export function roteamentoDaConfig(valor) {
  const config = copia();
  const avisos = [];
  try {
    const r = proprio(valor, 'roteamento');
    if (r === undefined) return { config, avisos };
    if (!ehObjeto(r)) return { config, avisos: ['config.json: roteamento inválido, usando os padrões'] };
    for (const k of ['negarN1', 'negarN2', 'avisos', 'sugerirSessao']) {
      const v = proprio(r, k);
      if (v === undefined) continue;
      if (typeof v === 'boolean') config[k] = v;
      else avisos.push(`config.json: roteamento.${k} inválido, usando true`);
    }
    const o = proprio(r, 'otimizacoes');
    if (o !== undefined && !ehObjeto(o)) avisos.push('config.json: roteamento.otimizacoes inválido, usando os padrões');
    else if (o !== undefined) {

// Sugestão para a sessão principal (spec roteamento §7). Só o hook decide,
// sem modelo. Precisa das últimas 15 respostas; null em qualquer dúvida.
const N = 15;
const SIMPLES = new Set(['Read', 'Grep', 'Glob', 'Edit', 'Write']);
const DESPACHO = new Set(['Agent', 'Task', 'Workflow']);
const ALTO = new Set(['high', 'xhigh', 'max']);
const BAIXO = new Set(['low', 'medium']);
const PENSAMENTO_MAX = 8000; // ~2 mil tokens

const simples = (r) => r.pensamento <= PENSAMENTO_MAX && r.ferramentas.length > 0
  && r.ferramentas.every((f) => SIMPLES.has(f.nome) && f.linhasMudadas < 40) && !r.ferramentas.some((f) => DESPACHO.has(f.nome));

function dificuldade(rs) {
  const falhas = new Map();
  for (const r of rs) for (const x of r.resultados) if (x.falhou && x.comandoHash) falhas.set(x.comandoHash, (falhas.get(x.comandoHash) ?? 0) + 1);
  if ([...falhas.values()].some((n) => n >= 3)) return true;
  return rs.some((r) => r.ferramentas.some((f) => f.reverte === true));
}

export function sugerirSessao({ respostas, modelo, effort }) {

    if (!Array.isArray(respostas) || respostas.length < N || typeof modelo !== 'string' || typeof effort !== 'string') return null;

  } catch {

  }

// Otimizações da sessão (spec roteamento §9: O1, O2, O5). Puras; o hook
// decide quando chamar. Nunca lança.
const O1_VEZES = 3;
const O1_LINHAS = 300;
const O2_BYTES = 30 * 1024;
const O5_PAUSA_MS = 5 * 60_000;
const COMANDOS = new Set(['Bash', 'PowerShell']);

function o1(rs) {
  const vezes = new Map();
  for (const r of rs) for (const f of r.ferramentas) {
    if (f.nome !== 'Read' || !f.leituraInteira || !f.arquivoHash) continue;
    const res = r.resultados.find((x) => x.nome === 'Read');
    if (!res || res.linhasLidas < O1_LINHAS) continue;
    vezes.set(f.arquivoHash, (vezes.get(f.arquivoHash) ?? 0) + 1);
  }
  return [...vezes.values()].some((n) => n >= O1_VEZES);
}
const o2 = (rs) => rs.some((r) => r.resultados.some((x) => COMANDOS.has(x.nome) && x.bytes > O2_BYTES));
function acerto(rs) {
  const u = rs.slice(-5).map((r) => r.usage).filter(Boolean);
  const total = u.reduce((s, x) => s + x.entrada + x.cacheLido + x.cacheCriado, 0);
  return total > 0 ? (100 * u.reduce((s, x) => s + x.cacheLido, 0)) / total : null;
}
function o5(rs, s, faixas, agoraMs) {
  if (!s || typeof s.context_pct !== 'number' || s.context_pct < faixas.ctxAmarelo || rs.length === 0) return false;
  const a = acerto(rs);
  const pausa = agoraMs - rs[rs.length - 1].em;
  return (a !== null && a < faixas.cacheAmarelo) || pausa > O5_PAUSA_MS;
}
